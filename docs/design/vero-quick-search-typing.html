How it works

Enter searches everywhere: every field the Business admin made searchable, each with its own match (exact, starts with, contains).

Pick a field to search only there. Only fields that can match what was typed are offered: digits-only fields appear when the text is digits; dates stay in Filters.

Recently opened records that match show first, so a record you worked on yesterday is one click away. Only you see these.

Arrow keys and Enter work without the mouse. Escape closes the list.
