## Fixes

1. **Audit: "Daniel Reyes opened a record" shows "—" in the Record column.** Record-open events must show the record number like document events do. Find why (the lookup in task 0011 may only cover document targets) and fix it.
2. **Overview › Latest activity is filled with searches.** Show the latest *meaningful* events: documents opened, downloaded, printed or redacted, refusals, settings changes and deliveries. Leave out searches, page loads and other routine reads (they stay in Audit). Same 5 rows.
3. **Add or edit a sending system:** the open panel squeezes the detail card behind it until its table is unreadable (one word per line, cut-off columns). The panel should lie over the page as on the canvas, without reflowing what's behind it.
4. **Tenant IT › Storage:** a volume Tenant IT set offline reads "How full it is can't be read right now". Use the same wording as Platform operations: "Offline (set by Tenant IT)", with no warning tone.
5. **Search fields:** the sending-system picker cuts the name off ("Loan Origination Syste"). Make it wide enough for the full name, or as wide as its content up to the panel width.
6. **Filters:** add the canvas's hints inside the empty boxes (for example "12 digits" for an identifier with digits-only matching, "Any" for optional exact fields). Derive them from each field's settings; no hard-coded field names.
