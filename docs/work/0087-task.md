# 0087: Plan for remote testers (docs only)

Written 2026-11-24 by the design chat. Branch `plan/remote-testers` from `release/vero-r7`. Read only: no code, no app start.

The owner will run Vero on his laptop (not in the cloud) and let a few testers in another city reach it through a tunnel. Each tester has an account.

1. Compare two or three tunnel options for this (for example Cloudflare Tunnel and Tailscale Funnel): cost, whether testers install anything, HTTPS, who can reach it, how it is switched off. Recommend one.
2. What Vero needs for it: the browser sign-in's redirect and origin for the tunnel's address, Keycloak's public address, CORS and Content-Security-Policy, cookie and HSTS settings, the rate limits, what must never be reachable (actuator details, Vault, Postgres, Keycloak admin).
3. Tester accounts: Keycloak users and groups per role, demo entities and data (no real documents), how to remove a tester.
4. The owner's steps, exact and numbered, and what a session can do for him. Mark which steps are owner-only.
5. `docs/work/0087-plan.md` and report `docs/work/0087-report.md` with "No other product's name or behaviour in code" and "Decisions taken". Merge on green `ci-passed`.
