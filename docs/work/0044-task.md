# 0044: Fix 10, error wording on every screen (UI only)

Written: 2026-11-22, by the design chat. From the failure catalog (report 0034, "Proposed fix tasks" item 10). Branch `fix/screen-errors` from `release/vero-r7` (at `8b3a420`). Vero-only, frontend only.

**The owner approves for this task:** frontend changes only, plus Vitest as a dev dependency (item 5). No backend or schema change and no other dependency; if one seems needed, stop and ask.

## What to build

1. **One shared way to show an error** on every screen (except the viewer, done in 0043, which should use the same helper if it fits without changing its words). Four kinds, each with its own plain wording:
   - **refusal** (4xx with a code: the request can't be done as asked): the catalog's sentence for the code;
   - **not allowed** (401/403): "You don't have access to this" plus what to do (sign in again for 401);
   - **Vero's fault** (5xx): "Something went wrong in Vero" plus the reference, and for 503 "try again in a few minutes" (for SDV-SYS-018, wait the `Retry-After` seconds);
   - **network** (no answer): "Vero can't be reached. Check your connection."
2. **Show the code** whenever the answer has one, as `(SDV-XXX-NNN)`, and the **reference** for every 5xx, so a person can read it to their IT team.
3. **Export errors** (audit, reports) show the reference too.
4. **Never the raw server text:** no `err.message`, exception text or response body shown to the user anywhere. Today's uses are in `api.ts`, `Approvals.tsx`, `AuditLog.tsx`, `Notices.tsx`, `Operations.tsx`, `Reports.tsx`, `Sensitivity.tsx` (check all others too). Sentences come from `problemWords.ts` / the catalog; unknown codes get the kind's general sentence plus the code.
5. A small **frontend unit test** setup (Vitest) for the helper is approved: each kind, a known code, an unknown code, a 503 with and without `Retry-After`, a network error, and a check that a server message never reaches the text. Add the `test` script; 0042's CI runs it.
6. The screen tour: one step that forces a 5xx and a network error on one screen and checks the wording, code and reference.

Tests; full build; `ui:capture`. Merge through a PR (local build and tour until CI exists). Report `docs/work/0044-report.md`, with the line "No other product's name or behaviour in code".
