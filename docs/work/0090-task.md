# 0090: Named seats survive a restart

Written 2026-11-24 by the design chat. Answer to report 0075, question 1: **yes.** Branch `fix/named-seats` from `release/vero-r7`.

**Approved:** one changeset adding a small table (entity, month, hash of the person); no other schema change.

1. Named seats (stewards, Business Admin, IT Admin, Platform operations) are recorded per entity and month in the table, with a keyed hash of the person, never a name, subject or e-mail. The month's count is the number of rows, so a restart changes nothing and several Vero processes count the same people once.
2. Rows older than the current and previous month are deleted by the daily cleanup; usage numbers already in the ledger stay.
3. Tests: a restart mid-month keeps the count; two processes count a person once; the hash can't be turned back into the person; nothing personal in the ledger, export or logs.
