2. **Logs:** every DOC/SCH failure writes one log line with the reference and the exact cause (storage read, check failed, can't draw, changed while downloading, stopped part-way). WARN for refusals, ERROR for server faults.
3. **DOC-009, the one-time Highly Confidential grant** (owner answer 4 of 0034): the grant counts as used **when the first byte is sent**. A failure before anything leaves Vero (storage, key service, check) **gives the grant back**; once part of the file has left, it stays used. Today it is marked used before decryption starts (`ControlledDownloadService`). Tests for: success; failure before the first byte (grant back, still usable once); failure after part of the file (grant used); two downloads racing on one grant (exactly one gets it). Every case audited.
4. **Print** follows the same rule as download wherever print uses a grant.
5. **Screens:** the viewer and download show the code and the plain message from the catalog, and the reference for server faults; a short file shows DOC-009's message. Never raw server text.
