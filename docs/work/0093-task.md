# 0093: Release licence keys: the owner's procedure (script and guide, no keys)

Written 2026-11-25 by the design chat. Side session; branch `chore/release-licence-keys` from `release/vero-r7`. Since 0073/0075 a release build without release licence keys doesn't start. **No session ever makes, holds or sees a release signing key.**

1. Read how licence keys are built in (`META-INF/platform/licence-keys.json`, `licence-build.properties`) and platform-core 1.0.0's licensing guide (at its tag, read only).
2. `New-SDV-ReleaseLicenceKey.ps1`, which **the owner** runs on his own computer: makes the release signing key pair, writes the private key only to a folder he names outside every repo (this Windows user only), and writes the public part where the release build reads it. It refuses to overwrite an existing key and prints nothing secret.
3. `New-SDV-Licence.ps1` (owner): signs a licence for a customer or the testers from a small input file (entity, dates, seats); never contains a price.
4. Prove both with a throwaway key in a temporary folder that is deleted after, **without starting Vero** (side-session rule): a test with the module's own licence check accepts a licence signed by the throwaway key and refuses one signed by another key. The main session proves a real release start later.
5. Runbook section "Release licence keys" with the owner's exact steps and how to keep the private key safe (offline copy). Report `docs/work/0093-report.md` with the owner's command. Merge on green `ci-passed`.
