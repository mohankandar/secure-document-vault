**Changes from the upgrade**

4. Node: Vitest 5 runs only on Node 22.12 or later 22.x, 24, or 26 and later (not 25). Vite 8 needs 20.19+ or 22.12+. This machine has Node 22.23.5. README "Technology baseline" and `docs/operations/SDV_V1_GA_CLEAN_INSTALL_RUNBOOK.md` (prerequisites) now say this. There is no `docs/install/` folder; the runbook is where the installer prerequisites are listed. `Build-SDV-All.ps1` only checks that `node` is on PATH and was not changed.
5. Browser target: Vite 8 builds for "baseline widely available" (Chrome and Edge 111, Firefox 114, Safari 16.4 or later). Vite 5 built for Chrome 87, Edge 88, Firefox 78, Safari 14. Browsers older than the new target are no longer covered. Written in the README.
6. Config keys: none changed in this repository.
