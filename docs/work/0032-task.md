## What to build

1. **New Business administration tab "Reports"** (last), seen by Business admin only, with sub-tabs "Daily intake" and "Sensitivity" (the second comes in task 0033; show it disabled until then or hide it).
2. **Counts only:** no titles, file names, names or contents anywhere. The primary identifier is the most a row shows.
3. **"Today" is the tenant's time zone.** Use the tenant's time-zone setting if one exists; otherwise add one (default from the install configuration, shown read-only on the report) and list it in the report.
4. **Filters:** a day (or a date range, up to 31 days) and a sending system (All or one).
5. **Totals:** deliveries received; documents accepted and pages; exact duplicates (task 0031: acknowledged, not stored again); contracts = **distinct primary identifiers**, split into new (first time ever) and updated; refused at intake (with codes); failed after receipt. The word "Contracts" comes from the primary identifier's display name (e.g. "Patients").
6. **Breakdown by sending system**, each collapsible, each with a total row; within each, one line per delivery: request ID (as the sender sent it), time, primary identifier, documents, pages, duplicates, refused (code), failed. Long lists page or say "N more, in the CSV".
7. **Overall total** counts a contract sent by two systems once.
8. **Export CSV: one line per document:** SHA-256 checksum, request ID, sending system, primary identifier, pages, received time (tenant time zone and UTC), outcome (`ACCEPTED`, `DUPLICATE_ALREADY_STORED`, `REFUSED` with code, `FAILED`). Use the CSV formula guard (cells starting with `= + - @` are escaped).
9. Refusals: deliveries refused before a document exists still appear (request ID, time, sending system, code).
10. Error codes for any refusal on these endpoints, as in the other tasks.
