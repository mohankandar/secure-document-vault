On the Reports tab (Business Admin only, like the Daily intake and Sensitivity reports; same look, same CSV export with reference and fingerprint, same 0044 error helper):
1. **Storage now:** documents, pages and stored bytes, by sending system and by level (Standard, Confidential, Highly Confidential), with totals.
2. **Growth:** the same, added per month, for the last 12 months.
3. **Due for deletion:** per retention rule ("keep forever" shows none), how many documents reach the end of their retention in the next 30, 60 and 90 days.
4. **Held back from deletion:** how many documents would be deleted now but are kept because of a legal hold, a quarantine (rows or filter block), or both.
5. **Counts only:** never content, file names, titles or record identifiers. Reasons stay out.
6. Must answer quickly at a million documents (no full reads per screen load; use indexes or a summary kept up to date). Measure it in a PostgreSQL test and write the time in the report.
