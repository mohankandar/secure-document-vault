# 0086: Faster CI and local checks

Written 2026-11-24 by the design chat. Branch `chore/faster-checks` from `release/vero-r7`. Goal: the same checks, in less time. **Never weaken or skip a check, never raise a time limit.**

1. **Measure first:** the last 10 `ci-passed` runs (each job and step, from `gh run view --json`), and locally `Build-SDV-All.ps1`, both schema checks and `ui:capture`. A table of times in the report.
2. CI: cache Maven and npm (keyed on the lock files); run independent jobs in parallel (backend, frontend, schema checks); skip jobs whose paths didn't change, while `ci-passed` still waits for every job that ran; cancel a superseded run on the same branch.
3. Local: Maven parallel build (`-T 1C`) if the tests are safe for it (prove with three runs); a `-Quick` switch on `Build-SDV-All.ps1` that builds only changed modules and their dependents.
4. Schema upgrade check (about 500 s): find where the time goes; start from a saved dump at the last released changeset instead of replaying from the start, if the result is the same (prove it once both ways).
5. `ui:capture`: a `-Steps` filter and a smoke set, so a task can run only its screens.
6. Times again after; report `docs/work/0086-report.md` with before and after, "No other product's name or behaviour in code" and "Decisions taken". Merge on green `ci-passed`.
